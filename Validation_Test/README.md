# FeliX_Exporatory_Workflow
Demonstrating the complete pipeline of running exploratory analyses on the FeliX model.

## Requirements

- **Vensim DSS**: Required to run the model and execute sensitivity analyses
- **Python**: Dependencies listed in `environment.yml`

### Setup Instructions

1. Create a virtual environment using Anaconda with `environment.yml`:
   ```bash
   conda env create -f environment.yml
   ```

2. If using the `.bat` files, update the Python environment path in `config.bat` to match your environment location. By default, it points to:
   ```
   %USERPROFILE%\AppData\Local\anaconda3\envs\felixcheck\python.exe
   ```
   All `.bat` files will automatically use the path specified in `config.bat`.

## Workflow Overview

This workflow conducts sensitivity analysis and exploratory modeling on the FeliX model through four main stages:

### 1. Vensim Sensitivity List (`1_Vensim_Sensitivity_List/`)
Uses a sample document (e.g., `Test.csv`) to generate Vensim files for sensitivity analysis. The `generate_setup_files` script generates input, output, and constants files. Optionally, `generate_sobol_sample` can be used to generate Sobol sampling inputs. These generated files are output to a folder in `2_Vensim_Runs/`.

### 2. Vensim Runs (`2_Vensim_Runs/`)
Vensim executes the sensitivity analysis using the generated files. This step requires Vensim DSS (Decision Support System).

**Two ways to run sensitivity analysis:**

1. **Latin Hypercube Sampling (Default)**: `generate_setup_files` script sets the sampling method to Latin Hypercube by default. This is suitable for general sensitivity analysis, feature scoring, and PRIM analysis.

2. **Sobol Sampling (Optional)**: Use the `{document}_sobol.txt` file generated by `generate_sobol_sample.py` as the sampling input in Vensim. This method is only necessary if you intend to use Sobol sensitivity analysis.

After running the analysis, export the results to `3_Conversion_to_EMA/Vensim_Exported_Results/`.

### 3. Conversion to EMA (`3_Conversion_to_EMA/`)
Converts Vensim output results into a format compatible with the Exploratory Modeling and Analysis (EMA) Workbench.

### 4. Exploratory Analysis (`4_Exploratory_Analysis/`)
Loads the converted data to perform various exploratory analyses including:
- Feature scoring
- Parallel coord plots
- Sobol indices
- Other exploratory modeling techniques
